Story

Software Engineer by craft. Building since before university.

I started writing software before university, after discovering web development in secondary school. That early start shaped how I learn: build real things, understand the underlying system, then make it better.

I study physics alongside engineering, but I came to software by building it. My work spans backend services, real-time platforms, storage systems, blockchain programs, and full products — from first sketch to working software.

I care about how software behaves beneath the surface — architecture, data flow, failure modes — and about shipping things that are reliable, maintainable, and actually useful.
